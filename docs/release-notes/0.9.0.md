BookStoreBD for Android 0.9.0 keeps itself up to date, so you always have the newest features and fixes.

What is new:

- The app finds each new version by itself, when it opens and every few hours in the background
- New versions download and are checked automatically, then installed with a single tap
- On Android 12 and newer, once the app has installed an update itself, later updates install without any extra steps
- A notice stays in your notification shade until the new version is installed
- The app asks to be updated before carrying on, so everyone shops with the latest version; your cart and account are kept, and the website is always there in the meantime
- Check for updates in Account now always gives a clear answer

Requires Android 8.0 or newer.
