# Roadmap and website parity

BookStoreBD for Android aims to offer everything the
[website](https://bookstorebd-loum.onrender.com) does, with the comfort of a
native app. New shop features arrive on the website first and follow in the
app; features that only make sense on a phone are built here directly.

This page lists the website's features and where each one stands in the app.

| Status | Meaning |
| :---: | --- |
| ✅ | In the app |
| 🔗 | Opens the website's page from the app |
| 📅 | Planned, with the phase it belongs to |
| 🌐 | Kept on the website |
